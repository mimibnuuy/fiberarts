
# Sunglasses Case

## Materials

- **Cotton**\* fingering/4 ply/weight 1 yarn, one colour for case and optionally a second colour for cinching cord (can use same colour for both)
- 3.00 mm and 3.50 mm hooks
- Sunglasses for measurement reference
- Scissors
- Yarn needle
- Stitch markers (optional)

\*Cotton yarn should be used as it will not scratch the lenses.

## Steps

You can start with a starting chain or a foundation stitch row, whatever you are most comfortable with. I have included instructions for both.
